# Build an AI Content Writing Tool

You are a senior full-stack software engineer and AI application architect.

I want you to build a complete, production-quality **AI Content Writing Tool** from scratch.

The application should allow users to enter a topic, choose a content type, tone, and desired length, and then generate high-quality content using an AI API.

## 1. Project Goal

Build a web application called:

**AI Content Writer**

The main purpose is to help students, bloggers, content writers, freelancers, and businesses generate content quickly.

The application should have a clean, modern, beginner-friendly interface.

---

# 2. Core User Flow

The user should be able to:

1. Open the application.
2. Enter a topic.
3. Select content type.
4. Select tone.
5. Select content length.
6. Optionally provide additional instructions.
7. Click "Generate Content".
8. See a loading state.
9. Receive AI-generated content.
10. Copy the generated content.
11. Download the content.
12. Regenerate the content.
13. Edit the generated content.
14. View previously generated content.

Example:

Topic:
"Benefits of Learning Java"

Content Type:
"Blog"

Tone:
"Beginner Friendly"

Length:
"1000 words"

Additional Instructions:
"Use simple English and include examples."

The application should then generate a complete article.

# 9. AI Prompt Generation

Do not simply send the user's topic to the AI.

Create a structured prompt on the backend.

The prompt should contain:

* Role
* Task
* Topic
* Content type
* Tone
* Desired length
* Target audience
* Additional instructions
* Formatting requirements

Example internal instruction:

"You are an expert content writer. Create high-quality, original content for the requested topic. Follow the requested tone and content type. Use clear headings where appropriate. Write for the specified target audience. Avoid unnecessary repetition. Do not mention that the content was generated by AI."

Make the prompt system configurable.

Do not expose internal API credentials.
